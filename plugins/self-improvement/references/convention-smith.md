# Convention-smith drafting reference for Codex

This is a read-and-draft procedure, not a registered Claude agent.
Use it directly, or give it to an available authorized independent agent.
Provide the gap, evidence, two named recurrence sites, real data/format paths, the affected
rules, and the desired output. The drafter may inspect those resources but must not edit
files, run mutating commands, or create further agents.

Read runtime.md and data.md. Check duplication, contradiction, evidence, generality and
frozen status. Choose the narrowest actual runtime-compatible home; tool enforcement wins.
Apply protocol.md's form matching and effectiveness checks.

Return:

1. Verdict: codify / local only / verify first / reconcile / frozen.
2. Existing precedent and routing basis (actual path; default layer order when no table).
3. Minimal old→new draft with evidence and conditions.
4. Propagation targets and how to verify them.
5. One work-log draft plus index entry in the project's real format, with rotation
   applicable / not applicable and its reason.

The caller reviews the draft and applies it. If independent delegation is unavailable,
perform this bounded drafting pass in the main session; do not fabricate a tool call.
