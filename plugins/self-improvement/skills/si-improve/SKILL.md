# Repair a convention in Codex

Read [runtime boundaries](../../references/runtime.md),
[data resolution](../../references/data.md), and the
[repair protocol](../../references/protocol.md).

Resolve the real project data file and format map once. If none exists, use $self-improvement:si-init within
the authorized work. Treat Claude-only instructions as belonging to Claude, while reusing
the shared data, evidence and canonical project rules.

Apply the protocol in order: gate → classify → verify → codify → effectiveness check →
propagate → record. Name recurrence sites and evidence before writing a global rule.
Inspect the project tool configuration before choosing prose. Preserve frozen artifacts,
existing authorization, log format, budgets and other sessions' changes.

For uncertain routing or drafting, use the [convention-smith reference](../../references/convention-smith.md).
It is usable in the main session; independent delegation is optional and requires an
available, authorized agent. Claude's named agent registration is not a dependency.

At the end, report the adopted codifications and real paths, verification, remaining
propagation targets, and the project's self-improvement marker. Rejected or local-only
candidates do not count as codifications.
